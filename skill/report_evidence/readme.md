# 通用报告来源核查

适用：任意FPGA题目的原始报告、基线/当前资源时序比较和文件身份检查。可换题目、板卡与工具，不依赖考场事件类型。

用法：在包根目录执行python skill/report_evidence/check_manifest.py --root . --manifest skill/report_evidence/manifest.json。复用于其他项目时，先人工审核新来源，再填写相对路径、SHA256与需检查的原文片段。

来源：大模型曾混淆事件编号与类型、把历史正常当当前在线；报告也可能混用不同构建的数字。因此把结论绑定到明确范围和原文件。

验证：本包七项来源分别对应语音版基线、当前实现报告、Flash读回、上电后观察和用户现场反馈，按原文件哈希及字段核对，validation_result.json是本轮实际输出。只能证明清单覆盖的来源一致，不能证明现场动作或识别精度。

失效条件：清单缺项、原日志错误、条件不匹配、文本字段含糊或未经审核就更新哈希。发现不符应停止引用并核查，不能为通过而自动接受新文件。
