# examguard 工具契约

本表对应工程[src/pc/host/app/agent_tools.py](../../../src/pc/host/app/agent_tools.py)的四个只读工具。MCP客户端可能给工具名加服务器前缀，应选择实际列出的对应工具。

| 工具 | 参数 | 主要解释边界 |
| --- | --- | --- |
| get_recent_events | time_range 可选1–1440分钟；event_code 可选80/81/96；limit 可选1–50 | PC接收时间UTC；默认最近30分钟；ET去重，AL另列；不把扫描结果说成全场总数 |
| check_evidence_status | event_ref 必填字符串 | 优先完整64位十六进制事务引用；状态含像素与历史采集联合校验 |
| get_image_path | event_ref 必填字符串 | 只返回实际校验通过的PPM路径、帧号、时间与SHA；不返回图像视觉判断或公网链接 |
| get_system_health | 无 | 最后状态、是否实时会话及有效温度；历史和停更不能证明当前在线 |

## 证据状态

| status | 应解释为 |
| --- | --- |
| complete | 联合校验完整，可供人工复核；不代表确认违规 |
| partial | 像素未收齐，不推断丢包数量或原因 |
| degraded | 历史采集存在缺口或窗口不完整 |
| failed | 历史取证结果报告失败，按实际字段解释 |
| awaiting_result | 已有像素但尚无可用历史结果，不能称联合完整 |
| awaiting_pixels | 有历史结果但像素尚不可查看 |
| invalid | 校验错误或关联冲突，拒绝自动认定完整 |
| not_received | 所选会话及证据目录未查到可关联证据；不能断定从未采集 |

source 与 scope 指定查询范围，不能解释为扫描了所有存档。完整事件引用不可缩短为仅UID重新绑定。数值为null表示未知，不是0。

## 编号与类型

event_uid是事件编号字符串；event_code是类型码整数，event_code_hex是同一类型的十六进制写法，event为类型标签。三个事件工具均返回类型字段，不从UID或缺失证据推断类型。

已核对的真实历史案例：UID102对应event_code=80、event_code_hex=0x50、疑似手机。102的十六进制虽为0x66，但不能把编号当成类型；当前事件名表也未定义0x66为扭头。字段缺失时不猜，字段未知时如实保留未知。

## 已知限制

最近事件查询是相对于查询时刻的窗口，不能直接遍历超过24小时的旧事件。用户已有完整引用时可以核对旧事件的证据；也可请用户明确选择新的当前会话。不能静默更改MCP启动参数。

独立MCP当前以“指定存档复核”标记，不包含实时监考台的内存快照，因此不据此出具实时在线结论。网页与桌面回放是独立界面，MCP的本机PPM路径不会自动成为网页图片。
