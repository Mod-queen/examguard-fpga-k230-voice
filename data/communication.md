# 模块通信链路

## 外部连接

| 起点 → 终点 | 接口 | 传递内容 | 对应功能 |
| --- | --- | --- | --- |
| K230摄像头 → K230 | 板载相机通道 | 640×480图像 | 模型推理与本机识别框 |
| K230 → FPGA | UART，115200，K230 UART1 IO9/IO10 | 身份、目标、头姿协议消息 | FPGA更新识别状态并判定事件 |
| OV5640 → FPGA | DVP，像素时钟/行帧同步/数据；配置接口写寄存器 | RGB565视频 | 实时显示、历史采样与遮挡统计 |
| FPGA ↔ DDR3 | MIG/AXI与内部读写通道 | 视频缓存、历史帧、窗口读取 | 持续显示与事件取证共享存储 |
| FPGA → HDMI屏 | TMDS | 1280×720画面、身份及考试状态 | 本地查看与提示 |
| FPGA ↔ 语音模块 | I²C | 词条播报请求、识别回复与轮询 | 身份信息确认、准备、求助和报警播报 |
| FPGA ↔ PC | USB串口桥，115200 | ST状态、ET事件、VI交互状态；PC下发配置与确认 | 监考台联动和场次记录 |
| FPGA → PC网卡 | 千兆PHY、RGMII、以太网/UDP | EG像素证据、HR采集结果 | 原始图像保存与联合完整性核对 |
| PC → 桌面Agent | 本地函数工具；模型服务使用配置的API | 所选会话事件、证据状态及可选图像 | 日常自然语言查询与辅助看图 |
| JoyCode → PC | MCP stdio | 四个只读工具调用和结果 | 自定义Skills、Rule、Prompt工作流 |
| 浏览器 → PC | HTTP登录会话 | 查询与复核界面 | 本机或已配置网络内的网页访问 |

K230的USB连接可供调试和PC查看运行回执；K230与FPGA之间另有硬件UART连接。JTAG用于配置与调试，日常演示可由Flash启动。

## FPGA内部跨时钟传递

控制、相机、DDR用户接口、像素显示和以太网使用各自的时钟。单比特状态采用同步链；事件和数据包采用握手或异步FIFO；多字段状态用快照整体传递。读写双方通过有效/就绪信号控制流量，避免将一次事件拆成不匹配的字段。

相关自检：[异步FIFO](../sim/modules/async_fifo.md)、[事件跨域](../sim/modules/cdc_event_transaction.md)、[状态快照](../sim/modules/cdc_stats_snapshot.md)、[证据包跨域](../sim/modules/evidence_packet_cdc.md)。

## 一次报警如何串起来

1. K230在自身相机画面中输出疑似目标，经UART交给FPGA。
2. FPGA结合考试阶段及确认逻辑接受事件，形成包含设备、启动、场次、UID、时间与类型的完整事件引用。
3. 历史调度器关联OV5640事件前后目标窗口；DDR保存或读取对应采样帧。
4. FPGA通过UART上传ET事件，通过网口上传EG像素与HR采集结果；语音队列同时安排本地提示。
5. PC按完整事件引用关联记录，检查校验、帧数与缺口，保存SQLite及图像文件。
6. Agent或JoyCode调用只读工具解释结果；老师在PC回放原始帧。

事件UID表示“哪一次”，事件码表示“哪一类”；只凭UID或仅凭图像数量不能替代完整关联。工具实际列出的帧数和AI实际抽样查看的帧数分别显示。

默认PC配置中的5005/5006是本机状态与下行桥接端口，6102用于图像接收，均可在配置文件中查看。MCP不另占FPGA/K230串口，也不是网页登录地址。
